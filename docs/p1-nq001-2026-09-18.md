# P1：NQ-001 评估与复现审计

## 本轮交付

本轮只新增评估工具、场景夹具、复现审计和离线测试，不修改生成、事实校验、修复、原子提交或路由收束核心。

- `test_support/nq001_live_eval.py`：固定 `model`、`prompt_version`、`package_id/version`、`route_id` 和临时 SQLite 路径；可启动绑定临时数据库的 API 进程，逐请求保存请求、响应原文、解析体、正文、状态、首字/完整正文耗时、usage 和失败阶段。
- `test_support/fixtures/nq001-scenarios.json`：覆盖告知、询问、等待、预设方向、自定义方向、重大永久后果、刷新/回看恢复、偏离路线、失败路线和自动结局，共 8 条路线、24 个步骤。
- `test_support/repro_audit.py`：只读盘点真实 CJK 字数、源 SHA-256、重复段落候选、reader/modules/package 绑定、版本目录唯一性，并尝试使用仓库构建器从固定 `analysis.json` 重建包；`--source-root` 可重复传入 `docs` 与 `content/source`。
- `tests_py/test_nq001_tools.py`：验证离线计划边界、CJK 计数和重复候选只报告不改写。

## 证据与判定

真实评估命令需要显式传入模型、提示版本、StoryPackage 版本、路线 ID，并使用 `--launch-server` 让评估器设置 `STORY_DATABASE_PATH`。每次运行输出目录包含 `run-config.json`、`report.json` 和 `calls/NNNN-<request-id>.json`。API 未冻结的字段会进入 `contract_gaps`，不会用本地推断填补。`--mode mock` 与 `--dry-run` 的状态分别为 `offline_mock_only` 和 `offline_plan_only`，两者都不能关闭 NQ-001。

指标按生成请求计算：首稿通过率、最终成功率、事实越权率、审查误拦率、修复成功率、首字时间、完整正文时间、方向可用时间、输入/输出 token 和失败阶段。当前 HTTP 契约没有稳定暴露事实越权、最终成功、审查误拦、修复成功的统一字段，因此脚本明确将这些项记录为 `null` 并报告缺口，不把未知当作零。

## 当前结果

本 worktree 未携带另一会话尚未提交的 P0 长篇运行包和 API 改动；已完成的验证是离线夹具计划和工具单元测试。尚未进行真实模型调用，因此没有 NQ-001 通过结论，也没有把既有 Mock/功能/终局证据改写为连续叙事证据。

P0 仍需冻结并提供：会话开局与回合返回字段、失败/事实冲突诊断、永久后果状态、刷新恢复语义、自动结局状态，以及最终成功/审查/修复指标字段。冻结后可以在同一命令上运行真实路线；若契约仍缺失，报告会停在对应阶段并保留完整请求与响应。

## 运行方式

```bash
python3 -B -m unittest tests_py.test_nq001_tools -v
python3 -B -m test_support.repro_audit \
  --source-root docs \
  --source-root content/source \
  --package-root content/packages \
  --output /tmp/story-repro-audit.json
python3 -B -m test_support.nq001_live_eval \
  --launch-server \
  --output /tmp/nq001-live-YYYYMMDD-HHMMSS \
  --package-id taixu-relics-part1 \
  --package-version 0.1.3 \
  --model "$STORY_LLM_MODEL" \
  --prompt-version "$STORY_PROMPT_VERSION" \
  --route-id nq001-longform-route-a \
  --stream
```

> 2026-09-20：P0 checkpoint `0.1.3` 已接入；长篇运行包自动盘点指向 `taixu-relics-part1@0.1.3`。确定性审计见 [p1-nq001-p0-checkpoint-0.1.3-2026-09-20](p1-nq001-p0-checkpoint-0.1.3-2026-09-20.md)。`0.1.2` 保留未覆盖。

最后一条命令只有在真实模型配置、P0 API 契约和十万 CJK 官方长篇包都可用时才有资格进入 NQ-001 证据；失败也必须保留输出目录，不能挑选成功样本覆盖失败。
