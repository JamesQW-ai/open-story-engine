## 两种表示

输入从 `source[].segments` 替换为 `source[].text`，保留原 `unitId`、空白和标点，可以完整还原原文。实体 E 引用及任务列表保持不变；实体出现位置改用 `anchor`。证据引用只使用单元 ID，取消对模型暴露的片段 ID，**没有取消实体引用这一不同职责的标识**。

| 方案 | 子串引用 | 主要取舍 |
| --- | --- | --- |
| quote | `[unitId, quote, occurrence]` | 模型复制逐字引文并选择从 0 开始的出现序号；程序求位置。引文越长，输出越长。 |
| offset | `[unitId, start, end]` | 单元内 Unicode 码点半开区间；输出更短，但模型需要准确选择数字位置，尚未实测可靠性。 |

条件前提及 nonPremiseUnits／unresolvedUnits 仍选择**完整单元 ID**，不得用子串代替完整前提。core、线索和来源范围才使用子串引用。旧 `P1-U2-S1` 这类片段 ID 在新定位器中直接拒绝，不自动去后缀，也不把失效引用搜索到相邻单元。

quote 模式拒绝不存在的引文、错误出现序号、空白引用、布尔序号、越界单元和跨单元引文。offset 模式拒绝布尔／浮点位置、空区间和越界范围；它使用 Python Unicode 码点计数，不是 UTF-8 字节或 JavaScript UTF-16 code unit。选择了合法但错误的引文或区间，只能判为“定位有效”，不能判为语义正确。

重复引文的序号在**整个单元**内重新计算，不沿用旧片段内序号。例如 control:mixed_people 的两次“议事殿”，旧片段内各为第 0 次，新单元定位须分别为第 0、1 次。测试验证了其绝对位置不变。

## 同片段内的定位精度

设计控制原文为“沈砚秋站在议事殿内并说‘我在殿外’”（实际夹具保留中文双引号和句号）。旧切分把整句作为一个片段；现在可选择三个互不重叠的子串：

| 手写角色标记 | quote 引用 | offset 引用 |
| --- | --- | --- |
| narrated_content | `["P1-U1","沈砚秋站在议事殿内",0]` | `["P1-U1",0,9]` |
| speech_cue | `["P1-U1","说",0]` | `["P1-U1",10,11]` |
| reported_content | `["P1-U1","我在殿外",0]` | `["P1-U1",12,16]` |

角色标记来自手写定位控制，**不是程序识别结果，也不会进入模型输入**。该检查只证明表示能准确指向这些范围，不能据此认定引文确为人物断言，或证明“我”指向哪个登记人物。

8 条控制还覆盖自述、他人转述、位置与字词共存、纯字词、重复引文、嵌套转述及未知说话人。嵌套和未知来源可以定位原文字词，但没有自动解析来源层级或将其升级为事实；它们仍是后续契约必须明确的未决边界。当前工具没有实现这些语义路由，不能把对应控制的定位成功叫作未决路由验收通过。

## 实测的是字符体积，不是模型效果

44 条控制统一按紧凑 JSON、未转义中文计算；两种新输入都保留一份原文和相同任务。旧响应是 assertion-scope/0.1 手写控制，新响应是保留旧语义字段、仅替换定位编码的 `assertion-locator-preview/0.1` 预览。

| --- | ---: | ---: | ---: |
| 输入字符总数 | 21,228 | 17,216 | 16,827 |
| 相对原输入 | — | -18.90% | -20.73% |

两种预览的 **113 处证据引用**均还原为相同绝对范围；实体锚点也逐条与原定位核对。并未因此调用旧语义评分器给新协议计分。

quote 的输入收益伴随输出增加，不能只报减少的一侧。若继续与更早的五分类手写响应 12,579 字符比较，quote 预览已经增加约 **27.65%**。当前没有新系统提示、真实 token、模型选择错误率或延迟数据；不能把这些字符差异当作正文质量或时延优化验收。

## 复审结论

1. **定位表示可表达，完整候选契约仍缺失。** `project_control` 仅用于已验证旧手写控制的离线预览；旧无效控制仍拒绝。它不会接受新细粒度候选、替模型推断主体或回写旧评分结果。
2. **原候选的主体锚点规则不能直接照搬。** 精确到“我在殿外”后，登记主体与说话人可能在核心子串之外。下一步需要明确外部主体绑定的证据及未决条件，不能简单放宽“必须包含主体”就将引语作为直接事实提交。
3. **统一 ID 不等于解决模型误选。** 已移除模型输入中两套证据 ID；模型仍可能选错单元、出现序号或字符区间。历史 ID 混用失败保持失败，没有自动修复旧回答。
4. **暂以 quote 作为下一步契约设计候选，offset 保留作体积对照。** 这是基于逐字引文可直接核对、可避免模型数字符的工程判断，不是实验确认 quote 更准。quote 的重复内容成本必须在完整契约预算中继续约束。
5. **原语义缺口仍保留。** 来源归属、嵌套／未知来源、旧非位置子类不可比、允许的等价引用范围均未验收，`readyForModelEvaluation=false`。本轮不生成生产候选或新的模型提示。
