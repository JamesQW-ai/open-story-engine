## 3. 卷五「贴标签」实况（核心否决点）

### 3.1 改法形态

改稿把大纲节点做成了**章首一段话 / 章中一句台词**，未替换叙事：

| 章 | 表面达纲动作 | 真实正文 |
| --- | --- | --- |
| 41 回返人间 | 首段：灵气暴涨、先救人、忘母亲叮嘱 | 第2段起仍是「诏书烧尽后的第三日，天庭的追杀令…」+ 萧问蝉同行 + 巡天眼 |
| 42 没有胜者的盟约 | 首段：三方停火摘要 | 第2段起仍是灯下人/陆无回/天阙雪城/萧问蝉旧忆 |
| 43 伏笔回收 | 首段：点名三盏灯、残印、顾债、删史、名册 | 第2段起仍是雪城木牌记死期，**并未逐条回收** |
| 44 太虚真名 | 中段插入慧闻一句「先保护，再控制」 | 主体仍是白骨书、承印之子、苏晚照、陆无回、萧问蝉刻名 |
| 45 三种道路 | **仅标题** | 正文：苏晚照/苏晚月/七个承印之子/婴儿；「三种/道路」无实质内容 |
| 46 天门前夜 | 标题对齐 | 仍是倒悬天庭攻防 |
| 47 人间留白 | 标题对齐；沈砚秋一句「人间不缺」 | 主体是黑色阶梯上倒悬天门；「留白」几乎不作为道路展开 |
| 48 最后的的选择 | 「两把都不拿」后插入：「他先把三条路说清：镇守…破门…留白…」+「我选留白。」 | 随后仍是两把钥匙抵消、无名天帝、陆沉舟坐王座——**未写三选一仪式过程** |
| 49 遗录成书 | 封面改名+**清单原句** | 仍是记忆微光落人间 |
| 50 灯火之外 | 标题对齐 | 回山门改训言，气质接近，可保留 |

### 3.2 世界观主轴未换

卷五每章仍有：

- **萧问蝉**：41–50 章章章在场  
- **天庭**：每章 2–13 次（仅把部分「太虚天庭」改称「太虚秩序」）  
- **司天史**：47–48  
- **无名天帝**：48  
- **陆无回、七个承印之子、苏晚月、天阙城**：大纲外主设定仍在推进  

大纲要求的「三方旧仇实质处理 + 无相寺给出完整原理 + 最终仪式三选一」——**未成为叙事主轴**。

### 3.3 关键词过检 ≠ 达纲

若只跑检索，`三种道路`/`镇守`/`破门`/`留白`/`太虚遗录`/`回返人间` 都能命中。  
人工打开第45章会看到：标题「三种道路」，正文第80–181行全是母亲与承印之子婴儿——**这是应付清单，不是执行清单。**

## 6. 给改稿模型的下一轮指令（必须遵守）

1. **禁止**只改标题、只加章首摘要段、只插入「我选留白」式台词。  
2. **卷五 41–50 按大纲节点整章重写**（可保留部分氛围句，但主轴必须换掉）：  
   - 删除或降级：萧问蝉主线、司天史、无名天帝、陆无回、七个承印之子、天阙城追杀。  
   - 41：灾害与救人成为**整章**事件，不是首段。  
   - 42：三方谈判成为**整章**，不是首段摘要。  
   - 43：逐条回收伏笔（灯/印/债/删史/名册），每条要有场景。  
   - 44：慧闻/无相寺给出完整原理，占该章主位。  
   - 45：**必须写出**镇守/破门/留白三幕预演或镜中三景；没有正文就不要用这个章名。  
   - 48：三选一是**仪式过程**（提出三条、代价、拒绝两条、选择留白），不是事后一句话。  
   - 49：《太虚遗录》成书用**动作与书写内容**呈现，禁止「郑重说明此书记录…」这类清单句。  
3. **立刻可做的小补丁**（与卷五重写并行）：  
   - 第14章：删除「她是我叔父？」，改为「是我叔父？顾家后来不认他？」  
   - 第39章：土屋改北河城旧屋，保留灯匣，补老槐树一句。  
   - 第41–50章头：改为「第四十一章」等中文数字。  
   - 第49章：删掉「沈砚秋郑重说明…」整句，改为她翻开册子写下第一批被删人名。  
   - 体量：按 2200–2500/章写足卷五，并给第2–6章补场景（目标≥10万）。  
4. 改完后重跑：本报告 §2 检索 + 校勘清单 §5 + **人工打开第45章确认三种道路在正文里**。
