- **大纲第45章要求的「看见镇守/破门/留白三种未来」在正文里不存在。**

## 4. 给改稿的硬性约束（防止第四轮再贴标签）

1. **禁止**在已有天庭线正文前/中再插「大纲摘要段」或「仪式规则说明段」。  
2. **第45章必须整章重写**：以「三种未来」为唯一主轴（镇守/破门/留白各一幕或镜中三景），不得再写苏晚照婴儿产房线作为主体。若要保留母亲线，只能压缩为一种道路里的一瞥。  
3. **第48章必须整章重写**：写成一场有动作、有对话、有落印的仪式；删除或彻底改写「两把钥匙都不拿」与三列落印并存的矛盾；禁止「他先把三条路说清…」这种解说腔。  
4. **第41–43章**：删掉章首摘要段，用场景重写承载大纲节点；萧问蝉/陆无回/天阙城要么删除，要么降到背景一两句。  
5. **第46–47章**目前几乎未动（1,698 / 1,722），须按「天门前夜」「人间留白」重写。  
6. 章头统一「第四十一章」等中文数字。  
7. 第39章：土屋 → 北河城旧屋，补老槐树。  
8. 体量：先重写 41–50 至 2,200–2,500/章，再给第 2–6、11–15 章各补场景，冲 ≥100,000。

**验收时必做**：打开第45章，检索「镇守/破门/留白」必须在**叙述句**中出现（不能只在标题）；打开第48章，通读仪式段，不得出现清单腔。
