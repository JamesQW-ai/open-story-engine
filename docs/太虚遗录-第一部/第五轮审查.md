## 4. 仍不合格

### 4.1 体量结构

- 24/50 章 &lt;2000；最短 **48=812、45=959**（恰是达纲关键章）。
- 卷二均 1857、卷四均 1977，仍偏低。

### 4.2 卷五主轴未统一

- 萧问蝉 41 次、天庭 56 次、陆无回仍在 42–44、司天史仍在 47。
- 41–43、46–47 仍是「补丁段 + 旧决战」，与 45/48 新写的北河城/河滩仪式**不在同一空间叙事**上，卷五内部断裂。
- 41 章「诏书烧尽后的第三日」与前 3 段「天门开启后第一日」时间线也未咬合。

### 4.3 记忆代价

- 第 42、47 章仍无稳定「具体失去」句。
