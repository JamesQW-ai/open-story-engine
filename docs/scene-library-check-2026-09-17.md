## 本轮交付

新增只读作者检查入口 `test_support/check_scene_library.py`。玩家端继续安全跳过坏素材；作者可通过本地命令查看被跳过的字段和原因，不必通过阅读页面猜测问题。

```bash
# 默认检查自动盘点中的全部十万汉字官方长篇
python3 -B -m test_support.check_scene_library

# 只检查其中一部，可指定独立素材目录验证修改副本
python3 -B -m test_support.check_scene_library --package-id taixu-relics-part1
```

可选 `--library-root <目录>` 替换素材根目录，仍只能选择达标官方长篇清单中的故事包。工具不建立数据库、不改清单、不下载或生成图片，仅向标准输出打印 JSON。需要保留报告时可重定向到新文件。

## 诊断口径

- 默认逐部检查当前冻结版本的 package ID、版本、母本 SHA-256 和支持的清单格式。
- 条目结构、审校标记、正则、人物条件、状态条件、重复素材 ID、优先级、文件摘要及实时提示词，复用 `scene_library.py` 的运行时校验。
- 文件检查共用目录边界和 SHA-256 规则，分别报告文件缺失、无法读取、路径越界、循环链接及摘要不符。
- 每个问题包含 `path`、`code` 和中文 `message`；例如 `/assets/0/required_text/0`、`invalid_regex`。JSON 解析失败额外报告 `line` 和 `column`。同时列出多个问题，不只返回第一个失败。
- 报告不输出正文、来源引文或生图提示词。清单不存在时明确失败，不以零条素材宣称已检查通过。
- `checked_assets`、`checked_live_rules` 是条目自身校验通过数；只要绑定或任何条目有错误，整份报告仍为 `invalid`。

退出码：`0` 表示本次结构／绑定／文件检查通过；`1` 表示报告发现清单问题；`2` 表示命令参数错误或指定故事包不在达标清单中。素材检查通过不代表全书素材已经齐全。
