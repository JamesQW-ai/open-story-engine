## 修正范围

本轮承接[议事殿留出复审](context-management-qualifier-heldout-review-2026-09-26.md)，新增 `qualifier-scope/0.2`，区分位置核心与完整限定命题。原 v1 提示、程序、金标和留出成绩 8/9 冻结，不在旧报告上重新计分。

[v2 契约实现](../test_support/context_qualifier_scope_v2.py)沿用原文引用定位和既有关系结构，改变作用范围的表达：

| 字段 | 职责 |
| --- | --- |
| `anchors.positionCore` | 被讨论的位置核心，包括位置自身的否定 |
| `anchors.qualifiedPosition` | 包含外层认识限定、条件前提的完整命题 |
| `limitations[].cue` | 触发限定的具体原文线索，可在核心之外 |
| `limitations[].scope` | 指向所限定的位置核心 |
| `limitations[].premise` | 条件前提，非条件类型为空 |

例如，“没有人敢断定沈砚秋在议事殿内”的核心是“沈砚秋在议事殿内”，完整命题包含“没有人敢断定”。线索位于完整命题内即可，不再错误要求其处于核心内部。原句仍输出 `needs_review / normal=null`，不能被转成“沈砚秋不在殿内”。

程序检查核心、线索、条件前提在完整命题中的包含关系；`scope` 须与核心一致。完整命题不可跳过中间非空白文字拼接，也不能跨越另一个独立句。句末标点／引号可保留；内部句号、问号、感叹号或分号触发保守诊断。该标点检查不是语法解析器，引用中含句末标点等复杂表达仍可能需要复核，不能据此判断语义必然错误。

所有提案原样保留；诊断不会删除标签或自动改变候选状态。无诊断也始终为 `semanticStatus=unverified`、`reviewRequired=true`，没有语义或生产批准。隐含作用关系仍须审核，完整命题的范围合法不等于线索必然支持标签。
