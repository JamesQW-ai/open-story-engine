## 本轮交付

将 39 个主要模型任务模板抽取到 `open_story_engine/prompts/`，新增统一加载与字段校验入口，保留迁移前措辞、空白、消息角色、数据输入范围和调用次数。本轮没有调整模型行为、用户界面、故事包或冻结母本。

主要调用模块为 `api_narrative.py`、`reader_actions.py`、`reader_consequences.py`、`cocreation.py`、`api_illustrations.py`。任务按 `reader`、`actions`、`consequences`、`core`、`legacy_rainy`、`legacy` 分组；兼容模板保留原调用条件，不扩大产品方向。短条件指令与上下文数据装配仍由原业务模块维护，未宣称所有提示词片段都已搬出。

模板内容 SHA-256 已接入正文成功/失败审计、官方开局记录及预生成规则版本。进程加载后固定模板快照，修改模板须重启服务。目录摘要变化会使旧准备草稿失效，正式分支不被改写；当前采用全目录摘要，未细分各任务依赖。

字段必须完整且不能多传，模板不会执行表达式，玩家输入中的模板标记或 JSON 括号原样保留。事实提取、授权审核等步骤继续使用原本独立的数据投影，没有改成共享一个包含全部答案的上下文。

首次尝试无隔离构建时，API 环境缺少 `setuptools.build_meta`；随后改用标准隔离构建，不向 API 环境额外安装构建依赖。安装包的资源验证另见本目录证据记录。

## 完成边界与后续

本轮是提示词管理重构，没有增加真实模型调用或重新验收生成质量，不据此宣称延迟改善。后续规则去重、措辞优化和减少无效修复应独立实施，并复验已有真实模型失败样本。人物图谱 C 和长篇节奏 D 的排期不变。

维护说明见 `open_story_engine/prompts/README.md`。运行测试使用临时数据库，没有修改现有故事分支。
