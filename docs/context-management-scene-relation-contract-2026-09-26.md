## 最小数据契约

数据见[关系与映射夹具](../test_support/fixtures/context-scene-relations-2026-09-26.json)，复核见[独立存放的复核记录](../test_support/fixtures/context-scene-relations-review-2026-09-26.json)。

| 对象 | 必需内容 | 用途及限制 |
| --- | --- | --- |
| `scope` | `snapshotId`、`branchId`、`packageId`、`packageVersion`、`sceneId` | 绑定同一包、场景和分支快照；任一变化则待复核 |
| 场景实体 | 局部 `id`、`kind`、来源定位 | 本例仅伤者和封山线；不推断伤者真实身份，不建立全局角色 ID |
| 来源定位 | `source.id`、`contentSha256`、原文 `span` | 引文和位置逐字匹配当前公开来源，来源全文必须未变化 |
| 来源关系 | 主体、关系、客体、值、肯否、时点、条件 | 本版仅当前快照中明确肯定的 `boundary_side`；不从否定补出唯一位置 |
| 正文映射 | `origin`、`draftSha256`、原文 `span`、完整 `statement`、`normal` | 同时绑定完整原稿、具体命题及原文位置；不能只保留命中关键词 |
| 复核记录 | 整份数据的 `artifactDigest`、复核者、范围、实体/关系/映射编号 | 由本地内容审核路径持有；模型返回的 `reviewed`、`authority` 不参与授权 |

`normal` 的本版字段为 `subject`、`relation`、`object`、`value`、`polarity`、`time`、`condition`。位置域有 `inside`、`outside`、`on_boundary` 三个互斥值；肯否为 `positive` / `negative`。对同一场景实体在同一边界的所在侧作比较，不将这套枚举推广到空间包含、模糊区域或其他关系。

本例来源关系明确为伤者在线外，因此正文“在线内”矛盾，“不在线内”支持。若来源只说“不在线内”，仍可能在线外或线上，本版不允许把该否定来源转换成唯一肯定位置。

## 来源、映射和权威的分工

1. 官方公开来源说明已经确认的场景事实。本轮读取既有冻结来源，逐字引用“陌生伤者与空灯被挡在封山线外”，没有增加故事情节。
2. Codex 将该来源整理为固定实验关系，并逐项检查主体、边界、所在侧及当前时点。该步骤仍需要语义审核，哈希无法证明理解正确。
3. 正文映射只说明“这一段实际断言了什么”，不说明断言为真。原始 C10 的跨度保留“目光从你脸上移到封山线内那道伏着的人影上”，规范化命题仍为“伏着的伤者在封山线内”。普通视线动作与位置断言不混为一个事实。
4. 程序仅比较两项已经复核的结构。未复核的实体、来源关系或正文映射均返回 `needs_review`。即使单个命题得到 `supported`，`proseAcceptance` 仍为 `false`，不代表同段其他命题或完整正文通过。

复核文件与数据文件的分离提供可追溯的内容绑定，不是数字签名或权限系统。当前二者都由 Codex 整理；不能声称获得了独立审核者的语义保证。未来模型候选不得获得写入复核文件的通道。

## 有效期与分支行为

本版采用最保守的快照有效期，避免尚无状态迁移证据就继承关系：

- 关系和映射仅在原 `scope` 内使用。旁支、子分支、新回合快照、章节/场景或包版本变化，均不自动沿用。
- 来源全文变化、引文位移、来源不再公开、原稿变化、命题变化或结构变化，都使原复核失效。
- 同一主体与边界出现冲突的受审位置，整份关系输入拒绝比较；不按顺序挑一个，也不让模型选择。
- 当前没有永久角色映射、迁移日志或动态关系写回。后续如实现继承，必须由权威提交结果生成新关系记录，携带父关系、变化原因及新范围，再单独复核；这是后续设计要求，尚未实现。
- 历史时点、条件句及可能性限定不在本版可比较域内。候选带这些字段时必须待复核，不能删去限定套入当前肯定关系。事件关系另需事件身份，不能用时间词相同推断是同一事件。
