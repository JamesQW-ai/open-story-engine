本轮核查多页面共享预生成任务的租约、失败重试和前台接管，修复重试时丢失其他页面有效订阅的问题。

## 复现与修复

两个页面订阅相同方向，第一次生成失败。页面 A 点击重试时，`TurnDrafts.ensure` 创建新的生成尝试并清空订阅；此后即使页面 B 的租约仍有效，页面 A 的等待请求断开也会让重试任务因无订阅而取消。

新增回归先在修改前复现：预期重试任务为 `ready`，实际为 `expired`。修复后通过。

`open_story_engine/api_turn_drafts.py` 在替换失败尝试时复制清理后的有效订阅，保留原到期时间。重试不是其他页面的心跳，不替它们续期。已过期／明确取消的任务仍不继承订阅，前台等待计数仍属于新的生成尝试，历史失败审计和用量继续保留。

## 验证

`tests_api/test_longform_draft_lifecycle.py` 新增 5 项确定性检查：

| 场景 | 验证结果 |
| --- | --- |
| 共享失败任务重试，发起重试的页面随后断开 | 其他页面的有效租约保留，重试完成；原到期时间不变，过期订阅不继承 |
| 旧页面租约到期，另一页面续订在途任务 | 复用同一任务，旧页面释放不影响新订阅，只执行一次生成 |
| 前台已接管，所有页面后台租约到期 | 正在等待的前台请求仍能完成 |
| 排队期间租约到期，新页面恢复 | 旧尝试明确零调用、零 token；恢复后仅运行新尝试一次 |
| 同名订阅分布在不同会话／父分支 | 重复释放只影响指定会话和父分支，不取消其他任务 |

测试通过线程事件和受控时钟确定先后关系，不等待真实 45 秒租约，不调用供应商。
