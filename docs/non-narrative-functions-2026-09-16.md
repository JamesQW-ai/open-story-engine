## 已修复

| 功能 | 原问题 | 当前行为 |
| --- | --- | --- |
| 正文预生成取消 | 释放先于准备到达时，迟到准备重新创建任务 | 记录已释放订阅，迟到准备返回 `subscription_released`；恢复页面使用新订阅，内部前台接管不永久注销当前页面 |
| 图片任务取消 | 释放先到、上下文读取期间离页、服务关闭后仍可能排队 | 入队前复核订阅和服务状态；同一页面取消不影响其他有效订阅 |
| 图片页面恢复 | 旧响应覆盖新页面、重复轮询或重发绘制请求 | 每次页面恢复独立订阅，过期响应只释放自己的订阅；恢复只查询，绘制由显式点击触发 |
| 图片阅读体验 | 生成中缺少可取消占位、超时与取消未区分 | 固定比例占位，提供“取消本页配图”；超时／失败／取消有提示，正文与方向保持可用；查询连续失败最多三次后停止重试 |
| 状态契约 | 无法正式记录受伤与失踪，失踪人物可能沿用旧地点行动 | `injured`、`missing` 作为有证据的暂时状态持久化；失踪清除旧地点，后续行动须有明确找回结果；永久死亡／离队不可借受伤或失踪复活 |
| 人物展示 | 已有状态未贯通手记和人物图谱 | 状态必须有当前分支正文证据和后果记录，受伤使用独立样式；无证据仍为 `unknown`，存活不等于在场 |
| 审校图片复用 | 状态附带证据和分支来源后，与图片条件做整体相等比较而误判不兼容 | 对图片声明的必需状态字段逐项核对，允许额外来源字段；死亡／离队／失踪／受伤不匹配仍拒绝 |
| 图片用量 | 无法直接分离展示确认与未确认任务成本 | 新增 `display_confirmed` / `display_unconfirmed`，分别记录已报告 token、未知调用；未知总量和金额保留 `null` |

订阅注销记录为进程内 600 秒、最多 4096 条；容量满时拒绝新增注销，不挤掉有效记录。并非跨进程永久取消协议，也不承诺撤销已经发送给供应商的费用。图片展示回执代表已有可见性检测收到回执，不代表读完，缺少回执只能叫“展示未确认”。
