## 玩家看到的变化

- 进入正文先匹配已发布素材，符合场景和状态就直接展示，不再每页自动生成最多四张图。
- 三张图分别表现山门雨阶与封山石、试炼场旧剑痕、登记堂雨廊；无现代物、人物或关键道具。它们是局部环境镜头，不表示场景无人，也不提供额外通道或线索。
- 未命中时默认不配图。作者明确标记且有视觉价值的独特变化可提供“绘制这一幕”，玩家点击才调用生图。本批仅为山门封山石崩裂一类已发生变化预留该规则。
- 图片生成独立于正文及下一回合；等待时只显示一句提示，不留大块占位。失败也不自动重试、阻塞行动。
- 预设方向 ready 后只解析和预取公共素材 URL；没有选中的正文草稿不会生成私人图片。

## 素材与兼容性

独立目录为 `content/illustrations/{package_id}/{version}/`，不改冻结 StoryPackage。`manifest.json` 记录包版本、母本摘要、来源 Beat/场景、原文证据、地点、视角、外观版本、人物、状态条件、视觉禁忌、审核状态与文件 SHA256。发布接口校验文件完整性；未审核或文件不符的素材不可读取。

来源 Beat 只是溯源；实际 `beats` 条件可限制具体节点，也可为空以允许兼容的回归场景。匹配始终核对地点、视角、明确状态条件及本页文本条件。人物图必须明确满足在场、伤势/生死与外观版本；缺失信息不等于健康在场。道具通过 `required_state.itemOwnerCharacterIds` / `itemLocationIds` 等事实匹配，不为图片修改状态。

首批为环境图，不依赖人物存在。地点改变、明显场景破坏或天气不合时不使用。文本过滤是保守的关键词规则，尚不能证明任意长篇正文的视觉语义完全一致；后续复杂人物名场面必须补齐状态条件和逐场测试。

## 任务与成本边界

私人图片键绑定会话、分支、正文、状态和图片规则版本，公共资源不含私人剧情。图片单独使用一个执行位置，最多八个活跃任务；后台正文不占用该队列。优先保证已提交且明确请求的场景，不提供未选方向的后台生图。

每分支图片最多一次供应商请求（n=1）；调用前将预算占用持久化，失败、取消或重启都不再自动花费。排队未调用的任务取消后可再次主动申请。此上限是请求数量上限，不是固定金额；未配置经核实的单价时不能承诺货币上限。

页面通过独立订阅 ID 续租，租约 30 秒，服务器每秒清理一次。翻页、卸载和 pagehide 都撤销订阅；遗漏卸载也会过期。一个标签页离开不会取消另一个仍在阅读的订阅。多次点击同一任务去重。

排队任务取消后不调用供应商；正在执行的请求只能标记取消并丢弃迟到结果，当前供应商接口没有可用的撤销计费协议。HTTP 超时 45 秒，返回 URL 的下载超时 30 秒，总任务期限 90 秒；期限到达也不能保证供应商停止收费。记录取消阶段、已发请求、返回 usage、完成而未展示等信息，不把未知用量填成零。

公共图片使用 public 缓存，私人图片仍走会话/分支读取校验及 private 缓存。正文组件以图片加载完成且进入视口作为展示回执，未看到的结果不标为已展示。

诊断命令：

```sh
python3 -m open_story_engine.illustration_metrics data/illustrations
```

记录是本机单服务进程的诊断资料，不是供应商账单。重启保留预算及用量记录；不支持多进程共用同一队列的分布式调度。本轮没有增加后台管理页面。

- 核心 197 项、API 94 项、前端 11 项通过；TypeScript/Vite 构建、git diff --check 通过。
- 专项覆盖关闭供应商时复用、跨会话同 URL、版本/文件完整性、相同 Beat 下的未知/死亡/离队/受伤人物拒绝、道具归属、未选草稿零生图、队列上限、多订阅、排队取消、租约/期限、重启不重复计费和未知账单保留。
- [关闭在线生图的 HTTP 抽样](evidence/p2-2026-09-15/offline-http.json)：三开局命中，查找 8.6 / 10.8 / 9.7 ms；资源 HTTP 200，公共缓存。不是公网图片下载耗时或 P95。
- 桌面浏览器在在线生图关闭期间读取已有真实模型存档，确认三张图片均加载为 1536×1024；山门旧分支翻页仍可复用，正文/下一步正常。没有提交新的正式剧情。
- [浏览器展示回执](evidence/p2-2026-09-15/browser-metrics.json)：时间为组件开始匹配至图片加载且进入视口，可能包含用户滚动等待，只作为本地小样本。
- [真实供应商取消抽样](evidence/p2-2026-09-15/live-image-cancellation.json)：隔离测试场景使用实际 gpt-image-2.5-sunburst，请求开始后撤销最后订阅；约 45.3 秒超时，一次已发请求、usage 未知、无私人图片落盘、无重试。没有验证到供应商成功生图后的取消退费，也没有把 mock 结果说成真实图片成功。
