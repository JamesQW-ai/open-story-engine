## 指标口径

三项指标均从本次提交尝试开始，以 `performance.now()` 计时，单位毫秒；在 React 更新正文／方向 DOM 后记录，属于浏览器呈现阶段近似值，不代表显示器实际绘制时间，也不是供应商纯生成耗时。

| 字段 | 达成条件 |
| --- | --- |
| `first_text_ms` | 本次回合首次呈现非空正文；`reset` 不抹除玩家已见首字 |
| `full_text_ms` | 收到成功结果并呈现该分支完整、已确认正文；包括服务端审查、落盘等等待 |
| `directions_available_ms` | 正文完成后，当前分支至少一个方向按钮已呈现并可点击；不要求各方向预生成任务全部完成 |

当前服务端在 `done` 前还可能生成后续菜单，因此 `full_text_ms` 也可能包含该阶段；本轮没有拆分后端生成管线，不能据此宣称已降低模型延迟。菜单请求慢时不遮蔽已完成正文。

未到达的指标为 `null`。失败草稿、失败后恢复的上一页、其他历史分支不能计入完整正文。缓存直达正文时，首字和完整正文时间可以相同。无方向、终局或方向接口失败时不伪造方向可用时间。

同一 `request_id` 的重试使用独立 `attempt_id`，避免把前次失败等待混入重试耗时。记录包含会话／分支标识和结果，不包含用户输入或正文；保存在当前标签页 `sessionStorage['story-reading-timings:v1']`，最多 50 次尝试，里程碑变化时覆盖该条，并通过控制台 `[story-reading]` 输出。存储不可用不影响阅读。这是本地诊断记录，未接入集中统计。新开局流程的三项计时尚未接入，不标记整个 P2 完成。
