本轮将小说互动体验分成开场、续写与存档/手记三个部分实施。保留小说书架和添加小说入口，未将界面改名为“副本”。

本文保留同日各次迭代记录。当前实现和验收边界，以末尾“动态篇幅、剧情插图与人物关系图”及其链接记录为准。

## 已实现

- 四种身份从各自的现场切入，开场与后续正文使用第二人称限知提示，去掉机械身份说明。开场600—1000字，生成中可见插图与正文；完成后由用户进入行动页。
- 开场与续写均走 SSE；续写分段交付同一次行动，保存前确保2000—2500个非空白字符。片段失败最多修订一次，恢复已通过正文；失败不保存生成分支。约600字在自然段间插图，不等待图片生成。
- 创建请求支持重试去重与参数冲突检查。小说名、角色名组成默认存档名，重复自动编号，支持命名、最近进展与最后保存时间。
- 手记按当前路线显示目标、进度、角色已知线索、实际状态后果和已相遇人物；不显示整本角色背景/其他路线的结果。
- 历史节点先作为回看，点击“从这里重新选择”后才恢复行动入口。新选择创建分支，原分支保留。
- 已声明结局自动收尾；叶节点可主动结束。回顾只列该路线的真实选择及状态变化，关闭的路线不能继续写入，先前成功请求仍可重试恢复。

## 当前边界

- 图片是独立的既有场景资源，按正文/地点匹配；未实现每回合实时生成新图。小说 TXT 和源故事包不改写。
- 进度目前是已确认的路线阶段，雨夜故事采用三个中间检查点与源结局；其他小说先支持开篇/结局两端。它不是大模型对角色全部目标的猜测，也未实现小说专属失败判定。
- 正文仍有重复、过多环境描写及行为细节偏差。本轮是功能验收，未达到文学质量或完整原著事实逐句验收。
- 已有存档正文不会被批量改写；从书架重新开局可体验新开场，旧存档后续生成使用新叙事规则。
- 模型接口关闭连接后，会话内在途请求可以完成保存；用同一个请求ID恢复。暂未实现跨进程生成任务恢复或历史SSE事件重放。

正式环境检查：已启动8000写作API与5173前端，前端代理健康检查200、生成可用；正式数据库与小说TXT在服务重启前后SHA-256一致。现有存档可读取，未混入隔离测试存档。
## 续写兼容与故事手记修正

- 旧存档续写失败原因：第 5、6 条生成审计显示，历史第三人称正文影响了新续写，两次分段生成均未通过第二人称校验。已在 system 和每段最终写作要求中明确当前角色及历史人称兼容规则，并让修正信息指出具体角色。保留原有事实校验。
- 在原存档的 SQLite 副本中重放同一个“重新梳理线索”行动，真实模型流式续写成功并保存 2105 个非空白字符，首次 delta 1.23 秒，全程 22.57 秒，期间发生两次局部修正。输出见 `evidence/player-experience-2026-09-11/legacy-continuation.txt`。这是一次真实调用成功，不代表生成永不失败或正文质量已验收。
- 目标百分比下整合选择时间轴，页面标注完整的自定义行动／方向描述，保留“故事开篇”及分支来源；移除足迹页签。点击节点可返回对应页重选，已有路线保留。
- 人物可点击查看记忆卡，记录首次出现、最新记录页及当前路线正文摘录，可跳转重读。保留完整对话上下文，不推断 NPC 心理，不读取未展示的人物秘密；回溯与切换路线时重新计算。
- 分页目录默认仍不读正文；仅显式 `include_actions=true` 时提取选择摘要。人物信息与时间轴新增分支隔离回归测试。
## 续写误判修复与精简身份卡

- 最新失败审计为“未登记的可进入地点：你连隧道”。修复地点校验对否定、入口位置未知的误判，并修复“陈砚说末班车到站”被识别为陈砚本人到站的主语误判。真实新增地点、人物到达和物品状态校验仍启用。
- 原被拒绝的 2228 字草稿重放后通过校验；同一存档副本、同一选择再次使用真实模型，流式生成并保存 2020 字，首个 delta 1.04 秒，总耗时 18.33 秒。正文见 `evidence/player-experience-2026-09-11/location-guard-continuation.txt`。功能复测不代表所有模型输出或文学质量已验收。
- 人物弹窗替换为姓名、身份及一段最多 160 字的动态总结，移除“你记得的片段”、片段列表和重读链接。按当前已读路线整理公开身份、主要行动和表现出的立场；不将模型总结写入权威状态。
- `POST /api/v1/sessions/{session_id}/character-profile` 按需生成概况。身份直接复用选择页公开的 `menuDescription`，模型不得覆盖；概况输入来自该公开身份及所选路线已读正文，明确“你”对应的角色，保留上下文以识别人称指代。同一节点在当前服务进程内缓存，回溯／分支切换使用对应节点数据。长路线输入保留开篇与近期正文，概况侧重当前主要经历；不是逐项行为档案。
- 真实模型验证：陈砚在开篇被概括为站务员；第二页总结更新为回应寻人问题、建议上车寻找及表现出的保留态度。段落编号用于核对引用范围，不等于独立语义事实审查。
- 191 项核心测试、57 项 API 测试、9 项前端测试及构建通过。补充地点否定／肯定、说话者与列车主语、人物概况缓存／分支隔离和只读数据库检查。

## 完整章节续写与路线收尾

- 本次正式存档的最新失败审计（ID 9）是“大段循环重复”。续写改为整章生成，再以可删除的非关键段落缩短、在局部过渡补足或按问题段落修复；不继续追加同一场景凑字数。保留第二人称、2000—2500 个非空白字符和真实 SSE。局部修改后以流重置同步最终正文，不能保证所有修订过程逐字可见。
- 瞬时连接错误、空流或空 JSON 在单次调用内最多重试一次；正文最多三轮校验，局部修复不超过八段及原文一半。失败保留审计，不创建正文分支、不增加进度；同请求重试不会重复保存。现在的本机模型为 `deepseek-v4-pro:cloud`，单次请求上限 120 秒，关闭整段传输降级。
- 为《雨夜候车室》的四种身份分别编写四个有明确结果的场景，救援、撤离、证据核对、事故交接形成路线收尾。百分比由当前分支连续完成的事件产生：25%、50%、75%、100%；不是自由文本次数或模型评分。达成末阶段后关闭选项，回溯分支各自计算。当前版本不同选择主要改变行动方式，仍汇入该身份的阶段结果；并非任意自由行动都已支持独立结局。
- 续写同时检查源事实、玩家视角、人物地点、道具归属、重复正文和实际章末状态；新增事实审查及有限局部修复。修复计划移动被当作已经到达、手机求助语音与调查录音混淆、不同身份返回候车厅的阶段差异等问题。检查并非完整语义证明。
- 人物卡只从当前路线已读正文识别实际出场者，排除回忆、假设、旧录音及仅被提到的名字。弹窗保留公开身份与一段动态总结；正式唐栖旧存档当前只显示唐栖。其他路线的人物不会混入。
- 四身份的确定性回归均到达 100%，并覆盖失败不推进、请求去重、结局拒绝续写、回溯不覆盖原路线。68 项 API 测试、192 项核心测试、9 项前端测试及 TypeScript/Vite 构建通过；差异检查通过。
- 在正式存档的隔离数据库副本中，真实模型完成一条连续唐栖路线，四阶段分别为 2243、2197、2249、2347 字，最终 `completed`、100%、零后续方向。第 2—4 阶段首次输出分别为 1.139、1.643、2.923 秒，包含修订的总耗时分别为 61.12、23.46、19.94 秒。样本在实现迭代期间产生，最终章使用最终规则，并非一次运行验证了全部最终规则和全部身份。父子分支、正文及结果见 [路线验收证据](evidence/player-experience-2026-09-11/route-closure-results.json)。
- **质量边界：核心救援和交接已闭合，全文事实与文学质量尚未验收。** 人工复核仍发现签名字形、值班往事的补造，以及结尾对先前核对地点的回忆偏差；自动审查未全部识别。证据保留这些真实输出，不以 HTTP 成功代替质量通过。其他导入小说尚未拥有本轮的四阶段专属场景。
- 正式 API 已重启并通过 5173 前端代理健康检查，生成可用；正式存档可读取。本轮真实模型测试未写正式数据库，原小说 TXT 未修改。CUA 认证不可用，本轮未重复浏览器视觉验收。
