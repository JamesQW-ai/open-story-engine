# 未完之书 · Open Story Engine Web

当前唯一的前端入口为 `web/`，使用 React、TypeScript、Vite 和原生 CSS。书架、开局引导、导入、阅读与历史页已统一重构，不保留旧版界面切换入口。

## 启动

在仓库根目录启动可玩 API（复用现有 `.env` 模型配置）：

```bash
STORY_API_PLAY=1 STORY_LLM_STREAM=true STORY_LLM_TRANSPORT_FALLBACK=false \
STORY_LLM_TIMEOUT_SECONDS=120 STORY_LLM_REASONING_EFFORT=none \
  .venv-api/bin/python -m uvicorn open_story_engine.api:create_app --factory --host 127.0.0.1 --port 8000
```

在 `web/` 启动前端：

```bash
npm ci
npm run dev -- --host 127.0.0.1
```

打开 `http://127.0.0.1:5173/`。默认将 `/api` 代理到本机 `8000` 端口。隔离联调可使用 `STORY_DATABASE_PATH=/tmp/<test-name>.sqlite` 启动第二份 API，再以 `STORY_API_PORT=8001 npm run dev -- --port 5176` 指向该实例。不要把隔离测试数据写入现有用户会话。

## 体验与边界

- 书架：小说封面、书名与“添加小说”入口，辅以三步新手引导；桌面和手机均可直接添加 TXT，按钮不带装饰箭头。
- 开局：点击小说后显示 50 字以内的背景悬念和氛围图，再选择身份。《雨夜候车室》四个人物各有开场、位置与首轮行动；其他小说优先匹配该角色主导的最早已声明入口，使用自己的角色资料和原文片段。界面不展示节点选择。支持原著角色与允许的新角色。
- 阅读：身份开场与生成分支展示各自保存的正文，完整原著章节仅用于沿原著的页面。长文约每 600 字在段落边界插图分隔，单段过长时按句子拆分，保留全部内容；新增候车厅、站台与信号室插图，懒加载并预留图片尺寸。其他小说使用通用书页氛围图。方向选择和自由行动直接调用业务 API。
- 续写：通过 SSE 实时显示模型正文，提交中禁用重复操作，完成后保存并切换阅读页；失败保留原页和输入，允许使用原请求 ID 重试。未完成的输出可展开查看，不当作已保存进度。可选方向至少两个，每项展示具体行动说明；菜单不足时补充自由行动，仍走现有判定接口。
- 故事手记：桌面和手机默认收起，主动打开后查看人物、线索和足迹；支持关闭按钮、Escape 与键盘焦点约束。正文使用自然页面滚动，行动选项位于文末。
- 我的故事：游戏存档列表，支持继续与删除。删除前确认，成功后移除该存档与本地阅读位置；失败保留卡片并允许重试。`DELETE /api/v1/sessions/{session_id}` 仅在 play 模式开放，单事务删除全部关联记录，不删除故事包。
- 深浅主题：默认墨色，支持暖纸色；主题和每个会话的当前阅读页保存在浏览器本地。刷新恢复当前页，超过一页的历史记录自动加载。
- TXT 导入：UTF-8、最大 10 MB，正文至少 100 字。第一行书名，章节标题单独成行；示例为 `content/source/rainy-waiting-room.v0.1.txt`。
- 网页新开场以第二人称限知叙述，600—1000 字，通过 SSE 输出；续写分段生成同一回合，合计必须为 2000—2500 个非空白字符。段落局部校验失败最多修订一次，已经通过的段落保留；失败片段不写入故事分支。真实模型仍可能出现文学重复、常识细节与行为描述偏差，本轮不视作叙事质量验收。
- 我的故事默认命名为“《小说》· 角色”，重名自动编号，支持自定义命名、最近进展与最后保存时间。旧存档保留原正文，新规则作用于新开场和后续生成。
- 手记新增角色目标、路线阶段进度、可见线索与选择后果。进度依据脚本确认的剧情检查点，普通观察次数、字数与其他分支不增加进度；100% 表示当前路线抵达已声明结局，尚不等价于角色所有支线目标完成。其他小说先提供开篇/结局两端进度。
- 回看有后续的节点时，需要点击“从这里重新选择”才会显示行动选项；新行动追加分支，原路线保留。路线末尾可主动收尾，回顾只列该路线实际记录的选择与状态变化；目前支持已声明结局与主动放弃，尚未新增小说专属失败条件。
